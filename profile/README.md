# Unfenced

**Full-web browser access for AI agents.**

Read public, JavaScript-rendered, and authenticated pages as clean content.
Drive browser sessions on sites you authorize, with credentials filled by name
and explicit confirmation for submission actions.

## Start building

- [MCP connector, TypeScript SDK, and examples](https://github.com/unfenced-ai/unfenced)
- [Get access to Unfenced](https://unfenced.ai)
- [Connect your agent](https://app.unfenced.ai)

Connect directly through remote MCP, run the lightweight npm stdio connector, or
use the typed SDK in your own agent. The browser runs on Unfenced's hosted service.

Unfenced is in private preview. An admitted account is required for hosted access.
Our public client code is MIT licensed; the hosted browser engine remains proprietary.
